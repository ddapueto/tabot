## Ventajas Competitivas de Tabot

| Ventaja | Detalle | Quien lo tiene |
|---------|---------|---------------|
| IA especializada por empresa | System prompt + KB adapta al dominio | Nadie bien |
| KB auto-alimentado | Instagram posts → KB automatico | Nadie |
| Precio fijo predecible | $49-99/mes todo incluido | Pocos |
| Multi-canal real | WhatsApp + IG + Web en un inbox | Respond.io (pero caro) |
| Lead scoring inteligente | Reglas + IA, configurable | Nadie en este precio |
| Follow-ups multi-dia | Secuencias automaticas | Basico en algunos |
| Self-hostable | Deploy en VPS propio | Nadie (todos SaaS cerrado) |
